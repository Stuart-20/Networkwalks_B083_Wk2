## 📚 Introduction
In this report covers the discovers and finding of my week2 assignment under the internship program at [networkwalks](https://networkwalks.com/). The project included performing a footprinting  on the already allowed domain of "networkwalks.com" as the study case  and scanning of the network on my own LAN .

The study shows how a professional cyber tech can gather public information available about a target so that to draw measures on how to protect or attack the system 

All activities (commands) were performed using kali linux which was running in a virtue machine (VM) for the footprinting and a widows PC as the host to scan the network having installed with the zenmap .

 # *Activities included*
 - Network reconnaissance
  - Port scanning 
 - Zenmap installation

 ## 🛠️  Tools used
  |Tools | Aim |
  |------|----|
  |Linux & widows OS | OS used for reconnaissance and scanning |
  |hhois | shows public available domain registration details, date, server name |
  |whatweb | Fingerprint web technologies such as servers, CMS platform, plugins, and ip information |
  |nslookup | domain name to ip address using DNS |
  |curl -I | Inspects HTTP response headers from a website |
  |wafw00f | Inspects the firewall used in web application |
  |dnsrecon | Enumerate DNS records such as NS, MX, SPF, TXT, and SPV records |
  |zenmap (N-map GUI) | Scan the local subnet to identify live hosts, ip addresses and MAC addresses|
  |Widows CMD | Information about local ip's and MAC addresses |
